# BAEZTRIVE Explore

Herramienta de exploración de datos de desarrollo y desigualdad en América Latina, desarrollada por **BAEZTRIVE Data Studios**.

## Indicadores disponibles

| Indicador | Fuente |
|---|---|
| PIB (USD) | Banco Mundial |
| PIB per cápita (USD) | Banco Mundial |
| Población | Banco Mundial |
| Gini | Banco Mundial |
| Pobreza extrema (%) | Banco Mundial |
| Índice de Desarrollo Humano (IDH) | PNUD |
| Informalidad laboral (%) | OIT / ILOSTAT |

## Países

México · Brasil · Argentina

## Modos

- **País individual** — serie de tiempo para un país
- **Vs Mode** — comparación directa entre dos países

## Stack

- [Streamlit](https://streamlit.io)
- [pandas](https://pandas.pydata.org)
- [requests](https://requests.readthedocs.io)

## Correr localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```
